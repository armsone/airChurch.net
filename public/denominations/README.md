# 교단 배지 출처

배지는 교단을 잘못 연결하거나 변형된 도안을 쓰지 않도록 공식 총회가 직접 배포한
CI 파일을 최우선으로 사용합니다. 별도 CI 다운로드가 없으면 공식 홈페이지가 현재
헤더·파비콘·공유 이미지에 사용하는 원본을 보존합니다.

## 교회별 소속이 필요한 표기

- 여의도순복음교회와 청주순복음교회는 기독교대한하나님의성회 공식 총회 자료에 각각
  중심 교회와 청주지방회 교회로 확인되어 `기독교대한하나님의성회` 로고를 사용합니다.
- 제주순복음교회는 2026년 광화문총회 정기총회 개최 교회이며 담임목사가 해당 총회
  임원으로 확인되어 `기독교대한하나님의성회 광화문총회`로 구분합니다.
- `독립교회`와 세부 교단이 없는 `대한예수교장로회`는 하나의 교단이 아니므로 단일 로고를
  임의로 연결하지 않습니다.
