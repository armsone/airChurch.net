## 재사용할 실행 방법

```sh
python3 scripts/audit-public-events.py --output .codex-tmp/events-audit-첫회
python3 scripts/audit-public-events.py --previous .codex-tmp/events-audit-첫회 --output .codex-tmp/events-audit-다음회
```

출력 디렉터리는 실행마다 새 이름을 사용한다. 프로그램은 공개 행사 API만 GET으로 읽으며 AI·인증정보·관리자 API를 사용하지 않는다. 사이트 데이터나 수집 상태를 변경하지 않는다. 원본 응답과 해시는 파일에 저장하고 표준 출력에는 건수·실패·변경 ID만 전달한다. 성공한 실행만 다음 비교 기준으로 사용할 `state.json`을 남긴다. 확인 시각만 바뀐 행사는 내용 변경에서 제외한다.

전체 목록의 ID·날짜·출처 URL 형식과 지역·대상·유형·온라인·교회·7일·주말 필터를 확인한다. 페이지 크기 25로 나눈 목록이 전체 목록과 일치하는지도 확인한다. 요청마다 20초, 조건마다 최대 10페이지로 제한하며 누락·실패 시 0이 아닌 종료 코드를 반환한다. 네트워크 요청 사이에 실제 데이터가 변경되면 차이가 발생할 수 있으므로 자동 교정하지 않는다.
