# 앞으로의 계획 — 1~7단계 실행 현황

기준일: 2026년 9월 12일. 기존 단계별 기록과 공개 글의 계획을 대조한 내부 현황이다. 1단계의 현황 목록은 작성했으며, 2~7단계는 확인 가능한 표본에서 첫 실행을 마쳤거나 후속 보완 중이다. 전국 자료의 정확성, 실제 신청 성사, 장기 운영 가능성을 모두 검증한 상태는 아니다.

| 단계 | 실제로 마친 범위 | 남은 일과 완료 판단 기준 | 근거 |
|---|---|---|---|
| 1. 현재 상태 살피기 | 행사 탐색에서 공식 신청 안내로 이동하는 흐름과 교회 상세를 표본 점검했다. 기존 기능·정보 부족·새 보완 항목을 나눈 목록을 작성했다. | 이 단계의 목록 작성은 완료. 다음 표본에서도 같은 이용 흐름을 적용하며 목록을 갱신한다. 성능 비교는 별도 측정 전까지 판단하지 않는다. | [1단계 기록](plans-step-1-current-state-20260912.md) |
| 2. 정보 정확성 | 메뉴 문구로 생성된 인물 21개와 사역 21개, 잘못 연결된 사역 3개를 보류하고 정상 인물을 유지했다. 여러 교회의 공식 예배 표에서 요일·시각·장소·부서명을 대조해 원본을 보류하고 확인된 대체 기록을 등록했다. 출처별 추출과 승인 전 중복 방지도 보완했다. | 미확인 요일·숨긴 옛 표·동명 교회는 추정하지 않는다. 후속 묶음은 운영 재조회와 공개 안내를 대조해야 완료로 집계한다. 8교회 승인 116개(이번 신규 114개, 기존 정상 2개)를 확인했으며, 기존 75개는 원본을 보존해 보류했다. | [인물 교정](plans-step-2-clergy-accuracy-20260912.md), [예배 교정](plans-step-2-worship-accuracy-20260912.md) |
| 3. 참여할 행사 찾기 | 소리곰·지구촌 일부 공지·두란노 결혼예비학교의 공식 대상·비용·신청 방법 등을 상세에 보완했다. 날짜 필터와 대상 필터를 보완했고, 부부 대상 행사 두 건이 ‘가정’ 목록에 나타나는 것을 확인했다. | 공식 정보가 충분한 다음 행사 한 건씩 확장한다. 상세의 조건과 목록 필터가 맞고 공식 신청 창구까지 도달해야 한다. 잔여석·접수 완료·무료 여부는 근거 없이 표시하지 않는다. | [3~7단계 기록: 참여 안내·두란노·대상 필터](plans-steps-3-to-7-progress-20260912.md) |
| 4. 첫 방문 안내 | 성남 지구촌의 두 채플, 아현중앙·동해교회의 주소·공식 연락 및 방문 안내를 확인 가능한 범위로 연결했다. 대상 교회와 비교 교회의 공개 HTML로 적용 범위를 확인했다. | 공식 안내가 충분한 교회부터 한 곳씩 보완한다. 주차·대중교통·방문 장소가 없으면 미확인으로 남기고, 여러 채플을 한 주소로 합치지 않는다. 실제 방문 경험은 아직 검증하지 않았다. | [3~7단계 기록: 첫 방문·632번 운영 확인](plans-steps-3-to-7-progress-20260912.md) |
| 5. 교회와 행사 연결 | 성남 지구촌교회별 행사 목록에 확인된 7건이 연결되는 것을 확인했다. 같은 홈페이지의 외부 재단·교육기관 두 공지는 교회 주최로 합치지 않았다. | 다른 기관도 고유 식별과 실제 주최 관계를 확인한 뒤 연결한다. 행사 장소를 제공한 교회와 주최 교회를 구분하며 양쪽 탐색 경로를 확인한다. | [3~7단계 기록: 21시 27분 갱신](plans-steps-3-to-7-progress-20260912.md) |
| 6. 시간이 지난 정보 관리 | 일정 경과·취소·변경·원문 해석 실패를 구분하고, 후속 정상 수집에도 미해결 날짜 충돌 표시를 유지했다. 읽기 전용 관리자 진단과 다음 묶음의 실제 갱신을 확인했다. | 공지 1164의 날짜 충돌은 미해결이다. 네트워크 실패 후 재시도와 원문 수정 후 해제를 계속 확인한다. 장기간의 관리 부담과 누락률은 아직 검증하지 않았다. | [3~7단계 기록: 상태 관리·관리자 진단](plans-steps-3-to-7-progress-20260912.md) |
| 7. 한 분야부터 운영 | 첫 분야로 찬양·공연을 골랐다. 기존 행사 목록의 ‘찬양·공연 모아보기’와 주소에 남는 카테고리 선택을 제공했다. | 공식 공고가 꾸준히 확보되는지, 회차·예매 조건을 갱신할 수 있는지 소규모로 확인한다. 협력 기관 확보나 참가 성과는 확인하지 않았다. 지속 운영을 확인하기 전 새 나눔·공동 활동 분야로 넓히지 않는다. | [3~7단계 기록: 첫 집중 분야](plans-steps-3-to-7-progress-20260912.md) |

## 최신 확인 상태

- 예배 후속 묶음은 기존 원본 보존, 신규 중복 검사, 운영 재조회와 공개 HTML 확인을 마쳤다. 최신 누계는 위 2단계와 예배 교정 문서에 기록했다.
- 일정마다 공식 원문·원문 수집일·검토 승인일을 구분해 보여 주는 화면을 운영 버전 634에 배포했다. 여덟 교회 116개 일정의 원문 링크와 두 날짜를 실제 공개 HTML에서 확인했다.
- 기존 기록의 공개 API·HTML 확인과 브라우저에서의 실제 조작 검수는 구분한다. 확인하지 않은 조작·신청·현장 참여를 완료했다고 기록하지 않는다.

## 현실적인 다음 순서

1. **완료된 묶음의 근거를 보존한다.** 634 배포와 최신 예배 누계의 운영 확인을 마쳤다. 후속 수정도 기존 기록을 보존하고 확인한 범위만 집계한다.
2. **한 가지 이용 흐름을 다시 확인한다.** 지역·날짜·대상을 선택해 행사를 찾고 상세 조건을 읽은 뒤 공식 안내로 이동한다. 교회 상세에서는 일정별 출처와 첫 방문 안내까지 이어지는지 확인한다.
3. **정확성 보완을 작은 묶음으로 이어 간다.** 공식 원문이 명확한 교회 또는 행사 하나를 고르고, 조사·후보 준비·독립 검토·반영·공개 확인 순서로 끝낸다. 날짜 충돌과 미명시 요일은 별도 대기 항목으로 유지한다.
4. **찬양·공연의 유지 가능성을 확인한다.** 새 공고 확보, 지난 일정 구분, 변경 안내 반영에 드는 작업을 기록한다. 이 과정을 감당할 수 있을 때 방문 안내와 행사 연결의 범위를 늘린다.

기술적인 첫 개선은 기존 기능을 활용해 실제로 진행할 수 있었다. 계속할 수 있는지는 자료를 확인하고 고치는 일을 반복해서 감당할 수 있는지에 달려 있다. 현재의 목표는 빈칸을 모두 없애는 것이 아니라, 확인한 사실과 남은 의문을 구분하면서 이용자가 다음 행동을 선택할 수 있게 하는 것이다.
