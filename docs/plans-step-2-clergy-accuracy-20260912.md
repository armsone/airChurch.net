# 앞으로의 계획 — 2단계 인물 자료 정확성 첫 정리

2026년 9월 12일 운영 자료와 공식 원문을 확인했다. 원인 분석, 영향 자료 조사, 코드 검토를 세 에이전트가 분담하고 팀장이 수정·배포·운영 반영을 수행했다.

## 완료한 범위

- 메뉴 문구인 신청하기·안내·연혁·지구촌에서 잘못 생성된 인물 21개와 사역 21개를 공개 보류했다. 삭제하지 않아 원본·출처·복원 가능성을 유지한다.
- 김성광·지요셉·이동원에게 붙은 창원 지구촌교회 사역 3개는 성남 교회의 공식 홈페이지를 잘못 사용한 연결이므로 해당 사역만 보류했다. 실제 인물 자체는 유지했다.
- 이동원의 성남 사역, 김우준의 성남 사역, 홍성신의 창원 사역이 승인 상태인 것을 운영 상세 조회로 확인했다.
- 공개 목회자 API의 지구촌교회 검색에서도 가짜 이름과 위 3개 연결이 사라지고 정상 항목 7개가 반환되는 것을 확인했다.

## 재발 방지

1. 수집 HTML의 메뉴·머리글·바닥글과 항목 경계를 구분한다. 의심 문구는 자동 인물 후보에서 제외하고 수동 확인 대상으로 남긴다.
2. 준비·승인 파일 생성 단계에서도 같은 출처 검사를 수행한다.
3. 동명 교회 홈페이지를 이름 하나로 공유하지 않는다. 성남 지구촌교회 공개 번호 10017에 검증된 주소를 지정하고 창원에 잘못 붙은 주소를 사용하지 않는다.
4. 기존 인물 재사용 시 교회 고유 식별자 또는 이름·교단·지역을 함께 확인한다.
5. 운영 보류는 인물 번호·역할 번호·이름·출처·갱신 시각을 함께 검사한다. 인물 전체 보류는 승인 사역이 남아 있지 않을 때만 허용한다.

운영 첫 변경은 실제 반영됐으나 변경 개수 판정 때문에 실패 응답이 반환됐다. 재조회 후 중복 실행을 중단하고, 직접 변경된 행을 `RETURNING id`로 확인하도록 수정했다. 후속 44개 변경과 최종 재조회를 마쳤다.

## 검증과 배포

- 공식 지구촌교회 원로목사 페이지를 제한적으로 재수집한 결과 이동원·김우준 2명만 추출되고 메뉴 문구는 빠졌다.
- 소스 검토 및 빌드 완료. 별도 테스트 파일·테스트 실행은 하지 않았다.
- 소스 커밋: `e327d25e88661e25a4a18d5d1822441ca4213f51`, 결과 판정 보완: `24f7c5898b4d1d1066f8ea79d838a891bc153ffe`.
- 운영 버전 625 배포 성공. https://airchurch.net 에서 관리자 상세와 공개 API로 최종 자료 상태를 확인했다.

## 남은 일

이번 완료는 2단계 전체가 아니라 확인된 인물 오류의 첫 묶음이다. 행사 참여 정보의 누락, 공식 교회와 행사 연결, 방문 안내, 다른 교회의 잘못된 홈페이지 여부는 후속으로 진행한다. 과거 마이그레이션에 있는 37개 연결과 현재 운영에 남은 연결 수는 다르므로 과거 행 개수를 실제 수정 개수로 계산하지 않았다.
