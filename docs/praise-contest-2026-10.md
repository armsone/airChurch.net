# 에이처치 2026년 10월 찬양대회

## 목적과 참여

참가자가 본인의 유튜브에 올린 찬양 커버 영상을 에이처치에 등록하고, 자신의 참가 링크를 공유해 좋아요로 응원받는다. 참가 영상과 공유 유입을 모으고 대회 후에도 작품을 소개한다. 참가와 좋아요는 무료다.

## 일정 · 한국 시간

- 접수: 2026년 10월 1일 00:00 ~ 10월 15일 23:59:59.
- 좋아요: 10월 1일 00:00 ~ 10월 18일 23:59:59.
- 수상 확정: 10월 19일 00:00 이후. 마감 전까지 인정된 좋아요만 포함하고 결과를 고정한다.
- 일정 판정은 서버 시각을 사용한다. 자동 유지관리 또는 19일 이후 첫 조회에서 고정 결과를 생성한다.

## 페이지와 집계

- 주소: `/praise-contest`. 넓은 화면은 가로 4개, 태블릿 2개, 휴대전화 1개.
- 각 카드에 영상·곡명·참가자·좋아요 수·순위·공유 버튼을 표시한다.
- 좋아요 많은 순으로 실시간 정렬한다. 동점 및 좋아요 0개는 등록 시각, 등록 번호 순으로 정렬한다.
- 진행 중인 화면은 10초마다 서버 집계를 갱신한다. 자신의 좋아요는 저장 직후 반영한다.
- 브라우저당 하루에 대회 전체 중 한 작품에 1표. 한국 시간 자정에 다시 참여할 수 있고 같은 작품이나 다른 작품을 선택할 수 있다. 전날 표는 유지하며 전체 기간 누적 합산한다. 당일 누른 하트를 다시 누르면 취소하고 다른 작품에 투표할 수 있다. 지난 날짜의 표와 종료 후 취소는 허용하지 않는다. 서버 데이터베이스의 고유 제약으로 동시 요청도 중복 인정하지 않는다.
- 서명 쿠키가 삭제되거나 다른 브라우저·시크릿 창을 이용하면 동일인을 구분할 수 없다. 본인인증이나 부정투표 완전 방지를 보장하지 않는다.
- 공유 링크는 해당 참가 카드로 바로 연결된다. 공개 YouTube oEmbed 응답을 확인하지만 채널 소유권 인증을 대신하지는 않는다.

## 상금

| 순위 | 금액 |
|---|---:|
| 1위 | 500,000원 |
| 2위 | 300,000원 |
| 3위 | 100,000원 |
| 장려상 2명 | 각 50,000원 |
| 합계 | 1,000,000원 |

누적 좋아요 순으로 1·2·3위와 장려상 2명을 선정한다. 내부 정렬상 4·5번째 작품은 모두 장려상으로 표기한다. 접수 마감 기준 참가 조건을 충족한 공개 작품이 5개 이하이면 자동 취소한다. 투표·수상자 선정·상금 지급을 진행하지 않는다. 마감 이후 최초 서버 처리에서 판정을 저장하고 재개하지 않는다. 최종 집계와 실제 송금은 구분하며, 19일 수상 확정 후 수상자 본인·권리·수령 정보를 비공개로 확인한 순서대로 지급한다. 추가 심사 점수는 없다.

## 재업로드

영상 파일 대신 본인 유튜브 링크를 제출한다. 원본 파일 제출과 에이처치 채널 게시 동의는 참가 조건이 아니다. 채널 게시를 희망하는 참가자와 별도로 동의와 권리를 확인한다.

운영자는 `/admin/praise-contest`에서 별도 협의 전 → 원본 대기 → 권리 확인 → 업로드 준비 → 실제 게시 완료를 관리한다. 실제 게시 완료에는 에이처치 유튜브 영상 링크를 기록한다. 참가자의 유튜브 영상을 다운로드하여 무조건 복제하는 방식은 사용하지 않는다.

**자동 채널 업로드는 별도 연결이 필요하다.** 현재 사용 가능한 도구에서 에이처치 YouTube 업로드 연결을 확인하지 못했다. 실제 자동 게시에는 권리 확인된 원본 파일과 채널 업로드 권한이 필요하며, 연결 없이 완료로 보고하지 않는다.

## 운영 범위

접수·중복 영상 확인·브라우저 식별·좋아요·정렬·기간 제한·최종 결과 저장은 서버가 처리한다. 공개·보류 변경은 기존 관리자 로그인으로만 가능하고 사유를 남긴다. 마감 후 권리 문제 영상은 공개를 중단할 수 있지만, 다른 참가자의 확정 순위는 다시 계산하지 않는다. 개인정보는 공개 API에 포함하지 않는다. 접수 시 이메일·전화번호·은행명·예금주·계좌번호를 받는다. 전화와 계좌 묶음은 AES-GCM으로 암호화 저장하고 관리자만 별도 버튼으로 열람한다. 열람 기록을 남기며 1분 후 화면에서 가린다. 수상 결과와 계좌를 확인한 뒤 지급하며 실제 은행 송금 연결은 아직 없다. 투표 생성·취소는 DB 트리거로 원자적으로 기록한다.

본 기획의 총상금은 100만 원으로, 이전에 논의한 참여지원 50만 원보다 확대된 최신 사용자 지정안이다. 기존 기능비 50만 원까지 더해 월 150만 원을 자동 집행한다는 뜻은 아니다. 실제 결제·지급은 이번 개발 작업에 포함하지 않는다.
