# 앞으로의 계획 — 1단계 현재 기능과 부족한 부분

확인: 2026년 9월 12일 20:00~20:04 한국 시간.

## 결론

행사 탐색과 교회 안내의 기본 구조는 이미 있다. 새 메뉴를 만들기보다 **공식 원문에 있는 참여 정보를 제대로 옮기고, 잘못된 인물 정보와 교회 연결을 먼저 확인하는 것**이 우선이다. 1단계의 산출물인 기존 기능·정보 부족·기능 보완 목록을 아래에 구분했다. 이는 표본 탐색이며 전체 데이터의 정확성이나 실제 신청 성사를 보증하지 않는다.

## 실제 이용 흐름에서 확인한 것

1. `/events`를 열어 앞으로 1년·전국 조건에서 71건이 표시되는 것을 확인했다. 자체 찬양대회가 포함된 화면 수치이며, 현재 신청 가능한 행사 수가 아니다.
2. 지역을 서울로 바꾸자 7건이 표시됐다. 지역·유형·온라인·참여 대상 필터, 월 선택과 달력 전환 입구가 있다. 실제 선택 동작은 서울 지역 필터와 상세 조건 펼치기를 확인했다.
3. 9월 19일 토요일의 ‘2026 올인원 믹싱세미나 · 서울’을 열었다. 일정·장소·주최·참여 방식·원문·마지막 확인 시각은 나오지만, 대상은 ‘대상 확인 필요’이고 별도 신청 버튼은 없다.
4. 연결된 소리곰 공식 안내는 정상적으로 열렸다. 여기에는 음향 초보자·방송실 봉사자 등 대상, 참가비, 서울 장소의 주차 제한, 네이버 플레이스에서 해당 날짜를 예약하는 방법이 있다. 원문에 정보가 없어서 생긴 빈칸만은 아니다. 예약 제출이나 잔여 자리 확인은 하지 않았다.
5. 첫 화면에서 ‘지구촌교회’를 검색하고 경기 성남 교회 상세로 이동했다. 예배시간 22개와 공식 홈페이지·예배안내 링크는 보이지만, 해당 표본에서는 주소·지도 카드가 나타나지 않았다. 예배시간 내용의 원문 전수 대조는 이번 단계에 포함하지 않았다.
6. 교회 상세의 ‘전체 일정 보기’를 누르면 `/events?church=10017`로 이동하지만 0건이 표시됐다. 전국 목록에는 지구촌교회를 출처로 한 여러 행사가 보였다. 교회와 행사 사이의 연결 값 또는 공개 조건을 확인할 필요가 있다. 원인을 확정한 것은 아니다.
7. 교회 검색의 목회자 결과에 ‘신청하기’, ‘안내’, ‘연혁’이 이름으로 나타났다. 예: `/pastors/14939`, `/pastors/14940`, `/pastors/14134`. 메뉴 문구로 보이는 값이 인물 검색에 노출된 사실을 확인했다. 수집·승인 경로와 영향 범위는 다음 단계에서 확인해야 한다.

## 기존 기능과 보완할 부분

| 항목 | 이미 있는 것 | 정보 또는 기능의 부족 | 다음 조치 |
|---|---|---|---|
| 행사 탐색 | 지역·유형·대상·온라인 필터, 월·달력, 날짜순 목록 | 독립 행사 페이지에 ‘이번 주’나 임의 기간을 직접 고르는 입구가 없음. 홈에는 오늘부터 7일이 있음 | 기존 날짜 조회를 재사용하는 작은 화면 보완 검토 |
| 행사 상세 | 일정·장소·주최·대상·방식·출처·확인일 | 공식 원문에 있는 대상이 미확인으로 남는 표본, 참가비·준비물·신청 절차의 별도 표시 없음 | 실제 원문을 근거로 필드와 수집·표시 방식 보강 |
| 신청 연결 | 신청 URL이 있으면 버튼 표시, 없으면 공식 원문 | QR 또는 안내문 방식의 신청은 방문자가 원문에서 다시 찾아야 함 | 직접 URL을 추정하지 않고 공식 신청 방법을 짧게 안내 |
| 모집 상태 | 종료·취소·재확인 안내와 유효기간에 따른 목록 제한 | 공개 상태와 행사 종료일만으로 실제 모집 중임을 알 수 없음. 별도 모집 마감일·접수 상태 구분 필요 | 원문의 모집 조건을 행사 일정과 분리해 확인 |
| 교회 첫 방문 | 승인된 주소가 있으면 지도 연결, 예배시간, 공식 출처 | 표본 교회에 주소 카드 없음. 주차·대중교통·첫 방문 안내 전용 정보 없음 | 공식 방문 안내가 있는 교회부터 보강 |
| 교회↔행사 | 교회별 목록과 행사 상세의 조건부 주최 교회 링크 | 전국 목록에는 관련 행사가 있지만 표본 교회별 목록은 0건 | 이름 추정 연결 없이 실제 연결 값·기관 식별 확인 |
| 인물 정보 | 교회·목회자 검색 및 연결 | 메뉴 문구가 목회자 이름으로 노출 | 잘못된 인물 판별·유입 경로 확인을 최우선으로 올림 |
| 정보 정정 | 행사 오류 제보와 교회 정보 수정 경로 | 현재 수집과 승인만으로 품질이 보장되지 않는 사례 확인 | 원인 수정과 기존 영향 범위를 함께 확인 |

## 2단계로 넘길 순서

1. 메뉴 문구가 인물로 노출된 경로와 영향 범위 확인. 정상 인물을 이름만으로 일괄 제외하지 않고 근거를 확보한다.
2. 교회별 행사 0건의 원인 확인. 다른 지역의 동명 교회와 섞이지 않도록 기관 식별을 먼저 확인한다.
3. 소리곰 사례처럼 공식 안내가 충분한 한 출처에서 대상·신청 방법·비용 정보 보완 범위를 정한다.
4. 공개 보류된 예배시간과 주소·방문 안내는 공식 대체 자료가 확인되는 범위부터 보완한다.

## 가능성에 대한 판단

첫 개선은 가능하다고 판단한다. 기존 필터·상세·출처·연결 구조를 재사용할 수 있기 때문이다. 다만 데이터 정정과 수집 원인 수정이 함께 필요하며, 실제 모집 여부와 현장 참여 성사는 사이트 기능만으로 확정할 수 없다. 이번 단계에서 구현·데이터 정정은 하지 않았다.
