이 구현은 관람비와 신청 안내에 한정한다. 주최·기간·시각·판매 상태는 변경하지 않았다. 영화제의 새 조건이 실제 공개되었다는 근거는 아직 없으므로 위 미종결 상태를 유지한다.

## 23시 55분 후속 반영

649에서 영화제 가격·개최 주체·공식 예매 버튼 안내가 정상 수집 후 공개 상세에 반영됐다. 원문/코드만 확인한 상태를 넘어 실제 HTTP 200에서 기대 문구 누락 0건을 확인했다. 개최 시각·관람등급·현재 판매 상태는 확정하지 않았다. 멜론 미완료와 전체 운영 평가를 이 결과로 완료 처리하지 않는다. 현재 이 작업의 자동 재개는 3시간 간격 ACTIVE이며 서버상 재시도 가능 시각과 주간 잔여 50% 하한을 따른다.
