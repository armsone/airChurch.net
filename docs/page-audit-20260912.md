# 교회·목회자 공개 페이지 전수조사 — 2026-09-12

조사 대상은 사이트맵의 교회 1,782개, 목회자 15,393개 상세페이지다. 실제 HTTP 응답, 페이지 제목·대표 제목, 공개 목록과 이름 일치, 상세페이지 내부 링크, 페이지에 포함된 이미지 URL을 조사했다. 모든 교회·목회자의 이력이나 소속을 외부 원문과 새로 대조한 인물 사실 검증은 아니다.

## 수정

- 교회 상세페이지가 목회자 사진을 조회하지 않고 항상 기본 그림을 표시하던 오류 수정. 공개 승인·사용 근거가 확인된 사진만 개인 페이지와 같은 사진 API로 표시한다.
- 목회자 카드 사진을 누르면 해당 인물 페이지로 이동한다. 사역 기록이 여러 개인 카드의 React 키는 실제 역할 ID로 구분한다.
- 한소망교회 로고의 404 주소를 공식 로고의 로컬 복사본으로 교체했다.
- HTTP 502가 발생한 목회자 사진 22건을 공식 원본으로 복구했다. 김환의 사라진 원본은 연동교회 공식 교역자 안내의 사진으로 바로잡았다. 추가로 이석병 사진의 JPG 응답/BMP 실제 형식 불일치를 WebP로 정규화했다. 복구 사진 23건은 현재 DB의 공개 승인·사용 근거·원본 URL 일치 검사를 통과해야 제공된다.
- 사진 실패 응답을 캐시하지 않도록 수정하고, 새로운 외부 이미지 장애에는 기본 이미지 또는 안내 문구를 표시한다.
- 영상 썸네일은 임의로 조합한 mqdefault 대신 DB에 저장된 공식 URL을 사용한다. 접근 불가 영상은 원본 기록을 지우지 않고 공개 목록에서 숨긴다. 숨김은 oEmbed 접근 불가와 요청 썸네일 및 hqdefault의 404를 교차 확인한 ID로 제한한다.
- 예배시간 1,276건을 전수 대조해 58개 교회의 150개 오류 행을 확인했다. 한소망교회 3개 행은 현재 공식 안내로 교정하고, 나머지 147개 오류 행과 중복 2개 행은 공개 보류했다. 보류한 기록의 올바른 대체 일정은 아직 확정하지 않았다. 모든 데이터 수정은 조사 당시 updated_at이 동일한 행에 한정한다.
- 예배시간 수집기가 사경회를 인식하고, 장소에 다른 시각을 섞지 않으며, 성경 구절·차량 시간·장소 표제·월 숫자·불명확한 이름을 자동 승인하지 않도록 수정했다. 서로 다른 부서나 장소의 동시 예배는 합치지 않는다.
