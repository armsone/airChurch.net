# 앞으로의 계획 — 행사 탐색과 첫 방문 안내의 첫 실행

2026년 9월 12일, 공개한 「앞으로의 계획」의 3~7단계를 작은 범위로 구현하고 운영에서 확인했다. 전체 교회·행사에 대한 완료 선언은 아니다. 조사·원인 분석·독립 검토를 에이전트가 나눠 수행하고, 팀장이 통합과 배포 및 실제 조회를 담당했다.

## 3. 행사에 참여할 수 있는 정보

행사 상세에 공식 안내로 확인한 참가 대상, 비용, 신청 방법, 준비 사항과 신청 기간을 표시한다. 소리곰 안내 및 지구촌교회 공지 1167·1170·1171을 우선 확인했다. 원문에 없는 항목은 만들지 않는다. 기존 후보 자료에 보관하고, 행사와 출처·내용 해시·검토 상태가 맞는 자료만 공개한다.

지구촌 공통 메뉴의 신청 페이지가 모든 행사 신청 링크로 붙던 문제도 수정했다. 해당 공지 본문에 신청 방법과 함께 실제로 제시된 링크만 사용한다. 공지 1171처럼 확인되지 않은 경우에는 신청 주소를 비운다.

소리곰 서울 행사는 공식 안내의 9월 19일, 참가비 10만 원을 확인했다. QR 목적지의 날짜 매개변수와 상품 본문 날짜가 달라, 임의로 날짜를 바꾼 예약 주소를 만들지 않았다. 최종 예약 화면에서 일정을 확인하도록 안내한다.

## 4. 처음 방문할 사람이 필요한 정보

성남 지구촌교회(공개 번호 10017)에 한해 공식 첫 방문 안내를 연결했다. 분당·수지 채플의 주소, 연락처, 찾아오는 길, 주차 안내, 방문자 안내 장소를 구분했다. 주차가 무료라고 단정하지 않는다.

교회 이름만 같은 다른 교회에는 이 안내가 나타나지 않는다. 운영 페이지 10017에서 안내가 있고 비교한 다른 교회 10382에는 없는 것을 HTTP 응답으로 확인했다.

## 5. 교회와 행사를 연결

검증한 지구촌교회 공지만 공식 교회 번호와 연결한다. 교회 이름만 같거나 홈페이지에 게시됐다는 이유로 다른 재단·교육기관의 행사를 교회 주최로 바꾸지 않는다. 재단 공지 1152, 교육기관 공지 1162는 이 연결 대상에서 제외했다.

## 6. 지난 일정과 확인이 필요한 안내

일정이 지났다는 사실과 행사가 실제로 종료됐다는 사실을 구분한다. 취소·변경 안내가 있으면 해당 상태를 먼저 보여 준다. 원문 해석에 실패하거나 날짜가 서로 충돌하면 확인 필요 상태를 유지한다. 다음 수집에서 다른 정상 공지를 읽었다고 미해결 문제가 사라진 것으로 표시하지 않는다.

공지 1164는 머리글 기간과 본문의 날짜·요일이 충돌한다. 확인 필요 상태로 보류하며, 공식 주최 측이 일정을 변경했다고 단정하지 않는다. 현재 충돌 문구가 실제로 수정되면 다시 정상 처리할 수 있게 했다.

수집은 기존 요청 간격·로봇 정책·작업 잠금·시간 제한 안에서 진행한다. 관리자 갱신도 출처를 지정할 수 있도록 했으며, 갱신 요청이 곧 모든 문서의 처리를 보장하지는 않는다.

## 7. 첫 집중 분야

공식 자료를 확보한 찬양·공연을 첫 탐색 분야로 정했다. 행사 목록에 ‘찬양·공연 모아보기’, ‘이번 주’, ‘이번 주말’을 연결했다. 선택한 분야를 주소에 남겨 같은 목록을 다시 열 수 있다. 오늘과 주말 계산은 한국 날짜를 사용한다.

이 선택은 현재 확인 가능한 행사 자료를 기준으로 한 첫 실험이다. 주최 기관과의 협력 관계나 참가 가능 인원을 확보했다는 뜻은 아니다.

## 확인한 범위와 다음 과제

운영 버전 627·628에 걸쳐 배포했다. 빌드와 공식 원문 대조, 실제 공개 API·상세 HTML을 확인했다. 화면 조작을 통한 브라우저 검수나 별도 테스트 파일·테스트 실행은 하지 않았다.

다음에는 출처별 남은 공지가 순차 갱신되는지 확인하고, 공식 신청 정보가 없는 행사를 무리하게 채우지 않으면서 보완 범위를 늘린다. 방문 안내도 교회마다 공식 출처를 확인한 뒤 확장한다. 전체 계획의 실현 가능성은 이번처럼 범위를 좁혀 사실 확인·공개·운영 확인까지 마치는 방식에서 확인했으며, 전국 단위 완성도나 이용자 수요까지 검증한 것은 아니다.

## 21시 27분 운영 갱신 확인

출처의 실제 실행 예정·점유·후보 상태를 확인하는 관리자 진단을 버전 630에 배포했다. 비로그인 요청은 403과 캐시 금지로 응답한다. 공개되지 않는 진단이며 행사 자료를 변경하지 않는다. 대기 집계는 최대 500개 표본, 기존 행사 연결 후보는 최대 50개임을 명시한다.

예정 시각 이후 지구촌교회 다음 묶음 수집을 실행해 남은 기존 공지 5개가 갱신되는 것을 확인했다. 공개 교회별 행사 목록은 0개에서 확인된 7개로 연결됐고, 공통 메뉴 H01 신청 주소는 이 목록에 남아 있지 않다. 재단·교육기관의 두 행사는 교회 주최로 합치지 않았다. 원문 날짜가 충돌하는 공지 1164는 계속 확인 필요 상태이며, 후속 정상 묶음이 끝나도 출처의 미해결 표시가 유지된다. 이번 조회의 전체 공개 행사 API는 69개를 반환했다.

## 두란노 참가 안내 운영 확인

[일일 결혼예비학교 48기 공식 안내](https://biblecollege.duranno.com/biblecollege/view/seminar_detail.asp?smrnum=4197)를 대상으로 631번 버전을 배포했다. 같은 공식 페이지의 PC·모바일 요약에 있는 시각·장소가 일치할 때만 10:00과 서빙고온누리교회 b1 두란노홀을 사용한다. 참가비는 가격표와 수강안내의 커플 단위 금액을 서로 대조해 ‘커플 260,000원’으로 표시한다.

신청 방법과 선착순 접수 안내를 공식 문구에서 가져오며, 접수 종료 날짜나 잔여석을 만들지 않는다. 서로 다른 가격이나 요약이 발견되면 해당 값 또는 행사를 확인 필요 대상으로 남긴다. 다른 두란노 과정으로 이 규칙을 넓히지 않았다. 운영 재수집 후 실제 상세 HTML에서 시간·세부 장소·커플 비용·선착순 안내를 확인했다.

## 21시 49분 방문 안내·대상 필터 확인

632번 버전에서 [아현중앙교회 공식 오시는 길](https://ajmc.or.kr/Page/Index/85)과 [새가족 안내](https://ajmc.or.kr/Page/Index/34), [동해교회 공식 오시는 길](https://www.dhchurch.net/Page/Index/196)을 첫 방문 카드에 연결했다. 주소·대표전화와 아현의 역 출구·도보 거리·새가족 교육 문구는 원문으로 확인한 내용만 표시한다. 확인하지 못한 주차나 접수 장소는 만들어 넣지 않았다. 두 교회 및 기존 지구촌 안내가 실제 공개 HTML에 있고, 비교한 다른 교회 10382에는 안내가 없는 것을 확인했다.

두란노 결혼예비학교와 지구촌 부부사랑학교는 상세의 실제 참여 대상과 달리 ‘가정’ 필터에서 빠져 있었다. 정확한 두 공식 URL의 부부·커플 대상 문구가 확인될 때만 목록 분류를 보완한다. 등록조건이 있으면 초청 문구보다 먼저 사용한다. 버전 17 수집기로 두 출처를 갱신한 뒤, 공개 ‘가정’ 필터에서 두 행사를 모두 찾을 수 있는 것을 확인했다. 해당 필터는 기존 행사 한 개를 포함해 3개를 반환했다. 지구촌의 미해결 날짜 충돌 상태도 계속 유지됐다.
